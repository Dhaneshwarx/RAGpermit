# Company starter pack

All names except the chosen owner identity and all company facts are fictional examples, not verified company data. Replace them with approved information before real use. No passwords are included.

This pack contains six proposed user records and eight documents with three sections each. Dhanesh is the CEO, Priya the HR Manager, Arjun the Finance Head, Deepak the Engineer, Meera the Legal Counsel, and Kavin the Intern.

Do not overwrite an existing private users.json. Review and merge approved user records, preserve existing accounts, and create passwords separately with src.setup_password. Review every document permission before copying into a private workspace. Use a separate practice workspace if retaining fictional facts.

Clearance does not override department restrictions. The CEO can read the company profile, employee handbook and executive strategy, but not the restricted departmental documents in this pack. Change allowed_roles only after deciding which cross-department access is intended.
